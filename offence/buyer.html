This app requests text inference only. Suppliers see the context you send them. Model identity is a seller claim, not an execution proof. Output stays data; this app never runs model tools or grants suppliers access to your files.

1. Find your suppliers

No suitable offers? Keep your policy intact and try another seed. The app never sends prompts to an ineligible supplier.

2. Set your rules

Select models above, then save. The agent uses the alias auto. It cannot change these rules.

A latency ceiling excludes unmeasured suppliers. Context is a supplier claim; this version accepts at most 16 KiB of text input. Trust restrictions do not hide text from the supplier.

3. Control payment

Connect LND using the local wallet environment described in the download's README, then save to verify the network. Never paste wallet credentials into a website. A receiving Lightning address cannot pay for inference.

Amounts below are millisatoshis (msat): 1,000 msat = 1 sat. All limits start at zero. Delivered output is charged even if a later batch fails.

Fee reservations must cover one batch per output token. Daily reservations are conservative; incomplete or uncertain purchases keep their allowance reserved. Received-output cost above excludes routing fees and payments whose output could not be recovered.

4. Network settings

Seeds are replaceable. DNS names require explicit approval; gossip cannot silently authorize access to private networks.

5. Connect your agent

Use these settings in a compatible text-chat client. Tool calls, images and structured-output parameters are not supported.
