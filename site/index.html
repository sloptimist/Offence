03 / HARD-CODED CONVICTIONS

Open participation.
Clear rules.

An open network needs honest boundaries. Here's what Offence stands for.

No permission slip required.

No central registry, admission authority or mandatory intermediary. Start with a peer you know. Discover more from there.

Bitcoin. No new network asset.

Offence introduces no native asset or separate blockchain. Its payment protocol uses BTC over Lightning, with prices set by providers.

Trust is your call.

Model hashes identify files. Signatures identify claims. Neither proves which model actually ran. Buyers use their own checks and reputation; execution proof is optional, and a requirement for proof must never be silently dropped.

Your hardware, doing the whole job.

Each provider runs a complete inference request on hardware it controls. Offence is packaged for StartOS and Linux Docker. The software is MIT licensed.
